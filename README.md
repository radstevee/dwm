# dwm

This is my build of dwm. It works for me. It may not work for you.
Don't expect any support from me for this.

## Patches

- xresources
- scratchpad
- sticky windows
- true fullscreen
- xrdb
- swallow
- shiftview
- vanitygaps
- stacker
- hide vacant tags
- ipc
- fsignal
- whiteboard
- autostart
- anybar
- dock support
- more layouts (bstack, fibonacci, deck, centered master, ...)
- logging via sll

There are probably more patches I forgot to mention, just look at the code yourself.

Forked from [luke smith](https://github.com/LukeSmithxyz/dwm).
